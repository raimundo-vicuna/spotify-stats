# You song
> Search your best moments and stats on spotiy.
# Install
Install with [npm](https://www.npmjs.com/):
```sh
$ npm install
```
Complete the [.env.sample](/server/.env.sample) file and delete .sample extension

# Usage
>Run app:
```sh
$ npm start
```
